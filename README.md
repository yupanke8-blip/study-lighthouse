# 复习灯塔

先理解概念，再看例题、主动回忆和练习；支持同时备考多个科目。

## 使用

发布后，在 iPad 的 Safari 打开网站。学习内容和记录保存在当前浏览器，可从应用导出、导入完整备份。

## 部署

应用在 dist 目录，使用 Render Static Site。无构建依赖，无服务器、数据库或 API 密钥要求。render.yaml 包含部署配置。

Render 默认静态站点使用公开链接。个人导入资料和学习记录保存在浏览器，不会自动上传到 GitHub 或 Render，也不会自动在设备之间同步。

## 第三方组件

PDF.js、字符映射和 JSZip 的许可证随组件放在 dist/vendor 目录。
